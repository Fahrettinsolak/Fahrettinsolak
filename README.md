## 🇬🇧 English

I'm a Computer Engineer working on **AI-based energy production forecasting for canal-type hydroelectric power plants**, currently as part of a TÜBİTAK-funded R&D project. My work spans the full stack — from the forecasting models themselves to the systems that serve them.

**What I do**
- Build forecasting pipelines using LSTM, Random Forest, XGBoost and ensemble methods on time-series energy data
- Design and ship full-stack applications with React, Node.js, and PostgreSQL/TimescaleDB
- Work on embedded systems and battery management (BMS), including hardware-adjacent tooling for battery analysis
- Develop and maintain internal web platforms and ERP tooling for business operations

**Selected work**
- **Hydroelectric Energy Forecasting** — AI-powered generation forecasting system for canal-type HES plants, covering data pipeline, modeling, and a fault-prediction/maintenance-planning module
- **CamERP** — Frontend tooling and modules (finance & operations) for an internal ERP system
- **İYONGA** — A standalone battery sorting/analysis tool, rebuilt as a dependency-free HTML application

**Tech stack**

`React` `Node.js` `TypeScript` `PostgreSQL` `TimescaleDB` `Python` `TensorFlow` `C#` `.NET` `STM32`

Open to collaborating on AI/ML and full-stack projects. Feel free to reach out via LinkedIn.
